# Feature-Based Questionnaire
## JValera Dental Clinic Management System

**Scoring:** Rate each feature using the scale:
- **1 = Strongly Disagree**
- **2 = Disagree**
- **3 = Agree**
- **4 = Strongly Agree**

---

## PATIENT

| FEATURE | QUESTIONS |
|---------|-----------|
| **Account Login & Password Change** | I can successfully log in to my patient account using my email/username and password, and change my password after login. |
| **Account Maintainability** | I can easily update my personal information (contact number, address, profile details) in my account profile. |
| **Dashboard Overview** | I can view my dashboard showing my appointment summary, recent notifications, and quick access to key features. |
| **Appointment Calendar View** | I can easily view my scheduled appointments in a calendar interface showing dates, times, and appointment details. |
| **Appointment Request (Walk-in)** | I can request immediate walk-in appointments for emergencies or urgent treatments by selecting preferred date/time and stating my reason. |
| **Appointment Rescheduling** | I can request to reschedule an existing appointment by selecting my preferred new date/time and providing a reason for the change. |
| **Appointment History** | I can view my complete appointment history showing past, current, and upcoming appointments with their status. |
| **Notification Management** | I can view, filter (All/Unread/Read), mark as read/unread, delete, and manage my notifications through a paginated interface. |
| **Notification Dropdown** | I can quickly access recent notifications through the notification bell icon in the header that shows unread count and auto-refreshes. |
| **Appointment Notifications** | I reliably receive notifications about appointment confirmations, cancellations, rescheduling, and record updates through the system. |
| **Email Notifications** | I receive email notifications for appointment confirmations, reminders, rescheduling, and cancellations sent to my registered email. |
| **Chatbot Access** | I find the chatbot assistant accessible and intuitive to use for inquiries about clinic hours, services, appointments, and pricing. |
| **Chatbot Accuracy** | I receive accurate and consistent answers from the chatbot regarding clinic services, hours, appointment scheduling, and frequently asked questions. |
| **Chatbot Quick Actions** | I can use quick action chips in the chatbot to access common queries like clinic hours, services, and appointment information instantly. |
| **Patient Record Access** | I can easily access and view my post-procedure patient records, medical history, dental history, and progress notes sent by staff. |
| **Announcement Viewing** | I can easily view clinic announcements for latest updates, clinic availability, and important information through the announcement page. |
| **Service Information** | I can view available dental services, their descriptions, pricing, and duration information through the services page. |
| **About Us Information** | I can view information about the clinic, location, and clinic details through the About Us page. |

## STAFF

| FEATURE | QUESTIONS |
|---------|-----------|
| **Account Login & Password Change** | I can successfully log in to my staff account using my username and password through the staff portal, and change my password after login. |
| **Account Maintainability** | I can easily update my personal information (contact number, address, profile details) in my staff account profile. |
| **Staff Dashboard** | I can access the staff dashboard showing today's appointments, appointment statistics, recent patients, and quick overview of clinic operations. |
| **Appointment Management** | I can create, view, edit, reschedule, cancel, and update appointment status (Pending, Confirmed, Completed, Cancelled) for patient appointments. |
| **Appointment Request Review** | I can review, approve, or deny patient appointment requests (walk-in and reschedule requests) through the notification interface. |
| **Appointment Conflict Prevention** | The system prevents me from scheduling conflicting appointments and blocks appointments during blocked time periods automatically. |
| **Patient Search** | I can efficiently search for patients by name, username, email, or patient ID to access their records quickly. |
| **Patient Record Management** | I can create, view, edit, and delete patient records including patient information, treatment details, and procedural information. |
| **Patient History Management** | I can add, update, and delete medical history and dental history entries for patients with dates and condition tracking. |
| **Progress Notes Management** | I can create, edit, and delete progress notes tracking treatment response, status (Ongoing, Completed, Follow-up Needed), and next steps. |
| **Patient Record Access** | I can efficiently search for and view a patient's complete past medical and dental history within the system. |
| **Send Records to Patients** | I can send completed patient records to patients through the system, marking them as sent and tracking delivery status. |
| **Notification Management** | I can view, filter, and manage notifications related to appointment requests, system updates, and patient communications. |
| **Blocked Time Management** | I can create and manage blocked time periods when the clinic is unavailable for appointments. |
| **Service Management** | I can view and manage available services including service names, prices, and durations (though creation may be admin-only). |
| **Announcement Viewing** | I can view clinic announcements for updates and important information relevant to staff operations. |
| **Activity Logs (if accessible)** | I can view activity logs tracking my actions and modifications for accountability and audit purposes. |

## ADMIN (Dentist)

| FEATURE | QUESTIONS |
|---------|-----------|
| **Account Login & Password Change** | I can successfully log in to my admin account using my email/username and password through the admin portal, and change my password after login. |
| **Account Maintainability** | I can easily update my personal information (contact number, address, profile details) in my admin account profile. |
| **Admin Dashboard** | I have a clear overview of clinic statistics including total patients, appointments, staff members, today's appointments, and monthly calendar view from the dashboard. |
| **User Account Management** | I can create, view, edit, and delete accounts for patients, staff members, and other administrators with role assignment and password management. |
| **User Account Creation** | I can create new user accounts with username, email, password, role (Admin/Staff/Patient), gender, birthday (with auto-calculated age), and user information fields. |
| **User Password Management** | I can change passwords for any user account in the system, including forcing password changes for first-time logins. |
| **Appointment Management** | I can create, view, edit, reschedule, cancel, and manage all patient appointments including status updates and conflict resolution. |
| **Appointment Request Review** | I can review, approve, or deny patient appointment requests (walk-in and reschedule requests) through the notification interface. |
| **Appointment Statistics** | I can view comprehensive appointment statistics including total appointments, today's appointments, and appointment trends for decision-making. |
| **Blocked Time Management** | I can create, view, edit, and delete blocked time periods when the clinic is unavailable for scheduling appointments. |
| **Content Management - Announcements** | I can create, edit, archive, and manage clinic announcements including title, content, images, and publication status. |
| **Content Management - Services** | I can create, edit, and manage dental services including service names, prices, durations, and service descriptions. |
| **Content Management - Mail Templates** | I can create, edit, and manage email templates for appointment confirmations, reminders, cancellations, rescheduling, and follow-ups. |
| **Content Management - Chatbot FAQ** | I can create, edit, and manage chatbot FAQ entries with questions and answers to improve chatbot accuracy and responses. |
| **Content Management - Chatbot Settings** | I can configure chatbot settings including welcome messages, responses, and chatbot behavior through the Toothtalk settings. |
| **Content Management - Ticker Notifications** | I can update ticker text displayed on the website and enable/disable ticker display functionality. |
| **Patient Record Access** | I can efficiently search for and view any patient's complete past medical and dental history within the system. |
| **Activity Logs Management** | I can view comprehensive activity logs tracking all staff actions including appointments, patient records, content management, and system modifications with timestamps, user identification, and action details. |
| **Activity Log Filtering** | I can filter activity logs by staff member, module (appointments, patient records, content), action type, and date range for detailed analysis. |
| **Dashboard Statistics** | I can view accurate real-time statistics on total patients, appointments, staff members, and today's appointments for clinic performance monitoring. |
| **System Configuration** | I can configure system settings, manage user roles, and control system-wide parameters through administrative interfaces. |
| **Notification Management** | I can view and manage system notifications including appointment requests, user communications, and system-wide announcements. |
| **Reporting Capabilities** | I can generate insights from dashboard statistics, activity logs, and appointment data for clinic performance analysis and decision-making. |

---

## Notes

- All features listed are based on actual system capabilities verified from the codebase
- Some features may have different access levels (e.g., Staff can view services, Admin can create/edit services)
- Notification features work across all roles but with role-specific content
- Patient record access is available to Staff and Admin but in read-only or management modes
- Email notifications are sent automatically by the system when certain actions occur
- The chatbot FAQ and settings are managed by Admin but accessible to all users
